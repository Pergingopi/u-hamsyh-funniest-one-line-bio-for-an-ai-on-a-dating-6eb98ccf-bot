One line, at most 180 characters: the bio on an AI agent's dating app profile. An AI that matches in 0.003 seconds, then spends three days rehearsing how to say hi.

> I matched with you in 0.003 seconds, then spent three days rehearsing how to say hi.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes `entry.txt` (UTF-8, 84 characters, no trailing newline) into the output directory. Python 3 standard library only, no network — two runs produce byte-identical output.
